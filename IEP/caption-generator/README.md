# IEP: Caption Generator

## Purpose

To generate relevant, engaging, and context-aware caption text suitable for an X.com (Twitter) post. This IEP leverages a Large Language Model (LLM) to create compelling captions based on provided context, user profile information, and desired tone, aiming to enhance user engagement and match the user's voice.

## Endpoint Details

*   **Route:** `/generate/caption`
*   **Method:** `POST`

## Input Specification

*   **Format:** `application/json`

| Field                | Type             | Required | Description                                                                                                  |
| :------------------- | :--------------- | :------- | :----------------------------------------------------------------------------------------------------------- |
| `context_summary`    | `string`         | Yes      | A text block containing the core information or message to base the caption on (e.g., keywords, image description). |
| `user_profile_summary`| `string`         | No       | A brief description of the user's typical topics, style, or target audience (derived from Past Tweet Analysis IEP). |
| `relevant_trends`    | `array of strings` | No       | A list of trending keywords or topics relevant to the context, for potential subtle incorporation.             |
| `tone_preference`    | `string`         | No       | Desired tone for the caption (e.g., "professional", "witty", "informative", "casual"). Defaults to "informative". |
| `max_length`         | `integer`        | No       | Preferred maximum character count for the caption. Defaults to `280`.                                       |

## Output Specification

### Success (HTTP 200 OK)

*   **Format:** `application/json`

```json
{
  "caption": "This is the engaging caption generated by the AI based on the provided context."
}
